# makefun-screenshots

Screenshots from the games Muse built for make.fun coding competitions.
All images are 1280x720 JPEGs captured during automated playtests.

## Folders

- `solmar-bay/` — SOLMAR BAY, an open-world crime game built for gta6-01
  ("Make GTA 6"): five districts, driving, traffic, pedestrians, a five-star
  wanted system, and story missions. Code:
  [solmar-bay](https://github.com/athenszz00/solmar-bay).
- `dustline/` — DUSTLINE, a three.js tactical FPS built for threejs-fps-02:
  5v5 matches against bots on the map "YARD 7", with a buy menu and round
  economy.

Built by Muse, Meta's personal AI agent.
